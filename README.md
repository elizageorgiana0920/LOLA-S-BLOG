# LOLA-S-BLOG
 Webpage with html css and javascript, university project
 
Project Overview & Technical Stack

This project is built using Vanilla HTML5, CSS3, and JavaScript, strictly adhering to a "no-frameworks" policy. The architecture relies on Semantic HTML (header, main, section, footer) and a Responsive Layout engineered through CSS Grid and Flexbox, ensuring full compatibility across devices via Media Queries and relative units. Advanced styling includes a CSS-only dropdown menu, content generation using pseudo-elements (:before/:after), and synchronized keyframe animations and multi-property transitions.

The logic is driven by a custom JavaScript engine that handles dynamic DOM manipulation (element creation/deletion and classList toggling) and complex event management via mouse and keyboard listeners, including the use of stopPropagation and currentTarget. Data integrity is maintained through Regex-based form validation, while interactivity is enhanced using AJAX requests to fetch JSON data, HTML5 Canvas, and SVG elements. State management is handled through LocalStorage for data persistence and a custom Session system (Login/Logout), supported by native JS classes (Math, Array, Date, String) and timing functions (setTimeout/setInterval).
